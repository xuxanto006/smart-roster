## 关键实现坑
- fmt()/weekKeyOf() 走 UTC 切片，东八区会把周一算成前一日（周日）；weekKey = 周一前一天，因此 Monday = addDays(curKey(), 1)。新增的日期解析一律用本地 fmtLocal 再交给 mondayOf/weekKeyOf，避免错周。
- 按日期排的规则与按星期排的规则互不覆盖（pushRequest 的 hit() 带 date 维度），「每周二请假」不会被「9.15 请假」顶掉。

### 本轮新增的两个坑
- **switchView 必须显式写 `display:block`**：CSS 里 `.view{display:none}`，把内联样式清成 `""` 不会让它显示，反而继承 CSS 的 none —— 曾导致 5 项 E2E 失败。
- **E2E 里 reload 之后要重新 switchView**：刷新回到工作台，藏在其它 view 里的元素（#reqStaff 等）不可见，selectOption 会 30s 超时。
- 本地静态服务器要用 run_in_background 单独起（`python3 -m http.server` 会随父 shell 退出而崩，报 ERR_CONNECTION_REFUSED）；e2e_newreq_local.js / e2e_sharebox.js 默认端口已统一改 8733。
