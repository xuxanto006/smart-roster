## 连带修掉的一个隐患：测试脚本提取主脚本的正则

页面新增了带属性的 `<script>` 段后，所有测试里的
`html.match(/<script>([\s\S]*?)<\/script>/)[1]` 全部失效 ——
该正则只匹配**无属性**的标签，会从无属性的开标签一路跨到下一个 `</script>`，
把中间带属性那段的起始标签也吞进来 → `SyntaxError: Unexpected token '{'`。

**一次修好 54 个测试文件**，统一换成「遍历所有 script、跳过 src、取最长段」：
```js
(()=>{let b="",m,re=/<script([^>]*)>([\s\S]*?)<\/script>/g;
      while((m=re.exec(html))){if(/\bsrc\s*=/.test(m[1]))continue;
      if(m[2].length>b.length)b=m[2];}return b;})()
```
取最长比判断属性可靠 —— 主脚本必然是最长那段，不受新增脚本段影响。

**教训**：靠标签属性做正则匹配很脆；页面结构一变，全批测试同时失效。
选「取最大者」这种语义特征，比枚举排除项稳。

## 追加：替换后连带的测试适配（3 处）

## 追加：统计页 KPI 竖排「乱码」修复（21:57）

**修法（三处）**
1. `.trend-kpis` → `repeat(auto-fit, minmax(150px,1fr))`
   放不下时**自动减少列数**，保证每格≥150px（窄屏那条同步改成 minmax(130px)）
2. `.trend-kpi small/b/em` 加 `white-space:nowrap`（`small` 另加 ellipsis 兜底）

## 追加：统计页「乱码」真因= HTML 注释未闭合（22:18）

前两次改KPI 的 grid/flex 都**没治本**。真实原因是我自己做的一个错：

**21:05 重排统计页 5 个子视图按钮时，用正则替换文案，把注释的 `-->` 弄丢了**：
```html
<!--pnid:5R2yCpjybgrCrkkSLPwRzI>本周概览     ← 缺了结尾的 -->
```
浏览器从这一行开始把后面所有内容都当注释吞掉，直到遇到下一个 `-->`。
后果：`statsPanelMonth` / `statsPanelOverview` 等**整块从 DOM 里消失**，
统计页只剩一个 card，KPI 容器被压到 178px（正常应930px），中文逐字竖排。

这次 149 vs 144 → 立刻定位。用栈配对还能精确定位是哪几行：
```python
stack=[]
for m in re.finditer(r'<!--|-->', s):
    if m.group(0)=='<!--': stack.append(m.start())
    elif stack: stack.pop()
# stack 非空 = 有未闭合，栈里就是位置
```
修复：5 处`<!--pnid:XXX>` → `<!--pnid:XXX-->`（正则 `(<!--pnid:[A-Za-z0-9_\-]+)(?<!-)>(?!-)` → `\1-->`）

## 教训（重要）

1. **动带注释的 HTML 时，先数 `<!--` 和 `-->` 是否配平**。这是 5 个字符的检查，
   但漏了会让整页布局塌掉，且症状（"布局乱"）与病因（"注释没闭合"）
   看起来毫无关联 —— 我连着两轮在 CSS 上找错方向。
2. **这次是靠无头浏览器实测才定位的**：
   `chromium.launch({channel:'chrome'})` 用系统已装的 Chrome，
   不需要 `playwright-cli install-browser`（那个卡了 40 分钟装不上）。
   量 `getBoundingClientRect()` + 查 DOM 里元素是否存在，比推理快 10 倍。
3. **症状离病因很远时，停止猜测，去测。** CSS 改了没效果 = 假设错了。

**最终验证**（浏览器实测 1280×1280 视口）：
